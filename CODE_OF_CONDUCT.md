# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep criticism about the code. Harassment,
insults and dismissive behaviour are not welcome here, whoever you are and whatever
your experience level.

## Reporting

Report unacceptable behaviour to the maintainer at the address in the repository's
commit history, or open a private security advisory on GitHub if you would rather
not use email. Reports are read by the maintainer alone, and the reporter's privacy
is respected.

## Enforcement

The maintainer may warn, temporarily ban, or permanently ban a participant, following
the [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
of the Contributor Covenant.
