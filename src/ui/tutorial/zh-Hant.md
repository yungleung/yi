Yi 是一款在本機運作的筆記應用程式。你的筆記是你所選資料夾裡的普通 markdown 檔案。沒有帳號，也
沒有伺服器：你在頁面上看到的，就是留在磁碟上的文字。

## 從工作區開始

**工作區**是 Yi 讀寫的資料夾。左側的檔案樹就是它：

- 點擊筆記即可開啟；
- 用 **檔案 → 新增筆記** 建立一篇；
- 右鍵點擊資料夾或筆記，可以看到屬於它的操作。

如果還沒選擇工作區，Yi 會提議在「文件」資料夾下建立一個。之後要切換到其他資料夾，請使用
**檔案 → 打開檔案夾…**。

## 新增筆記

**檔案 → 新增筆記** 會詢問名稱，並在工作區裡建立一個 markdown 檔案。名稱會成為檔名；筆記也可以
在 frontmatter 裡有自己的 `title`。

每篇筆記都會在寫作時儲存。**檔案 → 儲存** 會再次寫入目前文字，**另存新檔** 會把副本放到別處。

## 在頁面中寫作

Yi 讓你在渲染後的頁面裡編輯 markdown。標題、清單、表格和程式碼都以它們本來的樣子顯示。游標進入帶格式
的詞語時，Yi 會顯示它周圍的標記，例如 `**粗體**` 或 `*斜體*`；游標離開後，頁面又恢復平常的顯示。

工具列的命令和選單相同。選取一個詞並點擊 **粗體**，或使用鍵盤：

| 操作 | 快速鍵 |
| --- | --- |
| 復原 | ⌘Z |
| 尋找 | ⌘F |
| 儲存 | ⌘S |
| 新增筆記 | ⌘N |

在 Windows 和 Linux 上，用 Ctrl 代替 ⌘。

## 用 frontmatter 給筆記命名

頂部兩條 `---` 之間的部分就是 **frontmatter**。其中的 `title` 是筆記的名字；即使正文沒有
`# 一級標題`，它也充當最上層的標題。

```yaml
---
title: 一篇有名字的筆記
id: 20261017120000
keywords: 筆記, 範例
---
```

`id` 是筆記穩定的識別，wikilink 可以用它來連結。

## 給頁面搭結構

要寫標題，先輸入標題文字。然後點擊行首，把標記放在文字前面：一級標題用 `# `，二級標題用
`## `，依此類推。井號後面的空格是必需的。例如輸入 `一個章節`，點擊 `一` 前面，再輸入 `## `。

### 二級標題

#### 三級標題

段落之間用空行分開。在有助於閱讀的地方使用 **粗體**、*斜體*、~~刪除線~~ 和 `行內程式碼`。水平線
可以隔開想法：

---

項目符號清單、編號清單和工作清單都是普通 markdown：

- 一個項目
- 另一個項目
  - 巢狀的項目

1. 第一項
2. 第二項

- [ ] 尚未完成的工作
- [x] 已完成的工作

要寫引用，在新行開頭輸入 `> `，再輸入引用的文字。每個引用的段落都以 `> ` 開頭；沒有這個標記的
行就在引用之外。

> 引用讓一段話與正文保持距離。

表格用直線書寫：

| 功能 | 用法 |
| --- | --- |
| 粗體 | 選取文字並點擊 **粗體** |
| 表格 | **插入 → 表格** |
| 程式碼 | 輸入圍欄程式碼區塊 |

## 程式碼、公式和註解

圍欄程式碼區塊會原樣保留程式碼：

```js
const answer = 42;
console.log(answer);
```

行內公式寫在 `$E = mc^2$` 中。獨立公式會佔據自己的區塊：

$$
\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}
$$

腳註是句子裡的引用和正文下方的一條說明。[^1]

[^1]: 這是腳註的文字。編號由 Yi 處理。

## 連結筆記和圖片

wikilink 按標題、檔名或 id 連接筆記，例如 `[[另一篇筆記]]`。輸入 `[[` 時，Yi 會列出它找到的
筆記。普通網頁連結寫成 `[顯示的文字](https://example.com)`。

圖片是普通的 markdown 圖片：`![說明](picture.png)`。相對路徑會在筆記旁邊尋找。圖片按鈕可以從
檔案或剪貼簿插入圖片。

## 引用你讀過的資料

引用使用 pandoc 語法：`[@smith2020]`。Yi 會在頁面中顯示格式化後的引用，並在匯出時把引用的作品
列在參考文獻下。

## 尋找與取代

**編輯 → 尋找** 會在筆記中搜尋；**編輯 → 取代** 會取代一處或全部符合。搜尋可以在顯示的頁面中
進行，也可以在程式碼區塊的原始碼中進行。

## 匯出筆記

**檔案 → 匯出** 提供 Word 文件、OpenDocument 檔案、LaTeX、HTML、EPUB 電子書、PDF 和應用程式自己
處理的 markdown。卡片會寫明輸出檔案。圖片會被帶入輸出；當所選格式無法容納 SVG 或 WebP 時，Yi
會把它們繪製成 PNG。

## 儲存版本

**檔案 → 儲存一個版本** 會把筆記目前的狀態保存在 git 儲存庫裡。只有你主動要求時才會建立版本，
版本面板可以讓你閱讀舊副本並與目前文字比較。

## 更多文件

**說明 → 文件說明**（`F1`）介紹範本、引用、匯出選項和其他進階功能。

應用程式會記住你開啟過的文件和你在其中的位置。關閉視窗再開啟，同一頁會回來。

## 一篇可以試寫的筆記

把下面這段複製到新筆記裡，再改一改：

```markdown
---
title: 我的第一篇筆記
---

## 我在寫什麼

一個有**分量**的想法，一個[連結](https://example.com)，還有一條腳註。[^1]

一個公式：$a^2 + b^2 = c^2$。

[^1]: 線下的註解。
```

這就是一篇 Yi 筆記的全部形狀：純文字、一點 markdown，以及寫作時容易閱讀的頁面。
