Yi はローカルで動くノートアプリです。ノートは、あなたが選んだフォルダにある普通の markdown
ファイルです。アカウントもサーバーもありません。画面に見えているものが、ディスクに残るテキストです。

## ワークスペースから始める

**ワークスペース**は Yi が読み書きするフォルダです。左側のツリーがそのフォルダです。

- ノートをクリックすると開きます。
- **ファイル → 新しいノート** でノートを作れます。
- フォルダやノートを右クリックすると、その項目の操作が表示されます。

まだワークスペースを選んでいない場合、Yi は書類フォルダの下に作ることを提案します。あとから
別のフォルダに切り替えるには **ファイル → フォルダを開く…** を使います。

## ノートを作る

**ファイル → 新しいノート** は名前を尋ね、ワークスペースに markdown ファイルを作ります。名前は
ファイル名になり、ノートは frontmatter に独自の `title` を持てます。

ノートは書きながら保存されます。**ファイル → 保存** は現在のテキストをもう一度書き込み、
**名前を付けて保存** は別の場所にコピーを作ります。

## ページに書く

Yi は markdown を、表示されたままの形で編集します。見出し、リスト、表、コードはそれぞれらしく
見えます。カーソルが書式付きの語に入ると、`**太字**` や `*斜体*` のような印が周りに表示され、
カーソルが離れるとページは普通の表示に戻ります。

ツールバーにはメニューと同じコマンドがあります。語を選んで **太字** を押すか、キーボードを使います。

| 操作 | ショートカット |
| --- | --- |
| 元に戻す | ⌘Z |
| 検索 | ⌘F |
| 保存 | ⌘S |
| 新しいノート | ⌘N |

Windows と Linux では ⌘ の代わりに Ctrl を使います。

## frontmatter がノートの名前になる

先頭の 2 本の `---` に挟まれた部分が **frontmatter** です。その `title` がノートの名前で、
本文に `# 見出し` がなくても最上位の見出しとして働きます。

```yaml
---
title: 名前のあるノート
id: 20261017120000
keywords: ノート, 例
---
```

`id` はノートの変わらない識別子で、wikilink から使えます。**設定 → 新しいノート** で、新しい
ノートが最初に持つ frontmatter を決められます。

## ページに構造を作る

見出しを作るには、先に見出しの言葉を入力します。そのあと行の先頭をクリックし、言葉の前に印を
置きます。1 レベル目は `# `、2 レベル目は `## `、さらに下も同じように増やします。シャープの
あとの空白が必要です。たとえば `ある節` と入力し、`あ` の前をクリックして `## ` と入力します。

### 見出し 2

#### 見出し 3

段落は空行で区切ります。読みやすくなる所で **太字**、*斜体*、~~取り消し線~~、`インラインコード`
を使います。水平線は考えを分けます。

---

箇条書き、番号付きリスト、タスクリストはどれも普通の markdown です。

- 箇条書き
- もう一つの項目
  - 入れ子の項目

1. 一つ目
2. 二つ目

- [ ] まだのタスク
- [x] 終わったタスク

引用を作るには、新しい行を `> ` で始めてから引用の文を入力します。引用する段落はそれぞれ
`> ` で始めます。この印のない行は引用の外です。

> 引用は一節を少し離して置きます。

表は縦棒で書きます。

| 機能 | 使い方 |
| --- | --- |
| 太字 | テキストを選んで **太字** |
| 表 | **挿入 → 表** |
| コード | 囲まれたブロックを入力 |

## コード、数式、注

囲まれたブロックはコードを書いたとおりに保ちます。

```js
const answer = 42;
console.log(answer);
```

インライン数式は `$E = mc^2$` です。独立した数式は自分のブロックを持ちます。

$$
\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}
$$

脚注は文の中の参照と、本文の下の説明です。[^1]

[^1]: これが脚注のテキストです。番号は Yi が付けます。

## ノートと画像を結ぶ

wikilink はタイトル、ファイル名、id でノートをつなぎます。`[[別のノート]]` のように書きます。
`[[` と入力すると、Yi が見つけたノートを候補に出します。普通のウェブリンクは
`[表示する語](https://example.com)` です。

画像は普通の markdown 画像です。`![説明](picture.png)` のように書きます。相対パスはまずノートの
隣、次に **設定 → 一般** の画像フォルダから探します。画像ボタンはファイルまたはクリップボードから
画像を挿入します。

## 読んだものを引用する

引用は pandoc の記法 `[@smith2020]` を使います。**設定 → 引用** で参考文献ファイルと引用スタイルを
選ぶと、Yi はページに整形された引用を表示し、書き出しでは引用した作品を参考文献の下に並べます。

## 検索して置き換える

**編集 → 検索** はノートを探し、**編集 → 置換** は一つの一致またはすべてを置き換えます。検索は
表示中のページとコードブロックのソースの両方で動きます。

## ノートを書き出す

**ファイル → 書き出し** では、Word 文書、OpenDocument、LaTeX、HTML、EPUB ブック、PDF、アプリが
処理した markdown を選べます。カードには書き出すファイルと変換設定が表示されます。画像も出力に
含まれ、SVG や WebP は選んだ形式が保持できない場合に PNG として描かれます。

## 版を残す

**ファイル → 版を保存** はノートの状態を git リポジトリに残します。版は頼んだときだけ作られ、
版パネルでは古いコピーを読んで現在のテキストと比べられます。

## アプリを自分に合わせる

**設定** では言語、画像フォルダ、引用、新しいノートのテンプレート、未保存の文書をスタックで
開くかどうかを変えられます。設定は変更したときに保存されます。ワークスペースは
**ファイル → フォルダを開く…** で切り替え、設定では変えません。

アプリは開いていた文書と、その中の位置を覚えています。ウィンドウを閉じて開き直すと、同じページが
戻ります。

## 試してみるノート

これを新しいノートにコピーして、変えてみてください。

```markdown
---
title: 最初のノート
---

## 書いていること

**重み**のある考え、[リンク](https://example.com)、そして脚注。[^1]

数式: $a^2 + b^2 = c^2$

[^1]: 線の下の注です。
```

これが Yi のノートの全体です。普通のテキスト、少しの markdown、そして書きながら読みやすいページです。
