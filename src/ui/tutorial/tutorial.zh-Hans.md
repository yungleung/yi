Yi 是一款本地优先的笔记应用。你的笔记是你所选文件夹里的普通 markdown 文件。没有账号，也没有
服务器：你在页面上看到的，就是留在磁盘上的文字。

## 从工作区开始

**工作区**是 Yi 读写的文件夹。左侧的文件树就是它：

- 点击笔记即可打开；
- 用 **文件 → 新建笔记** 创建一篇；
- 右键点击文件夹或笔记，可以看到属于它的操作。

如果还没有选择工作区，Yi 会提议在“文稿”文件夹下创建一个。之后可以在 **设置 → 通用** 中更改。

## 新建笔记

**文件 → 新建笔记** 会询问名称，并在工作区里创建一个 markdown 文件。名称会成为文件名；笔记也可以
在 frontmatter 里有自己的 `title`。

每篇笔记都会在写作时保存。**文件 → 保存** 会再次写入当前文字，**另存为** 会把副本放到别处。

## 在页面中写作

Yi 让你在渲染后的页面里编辑 markdown。标题、列表、表格和代码都以它们本来的样子显示。光标进入带格式
的词语时，Yi 会显示它周围的标记，例如 `**粗体**` 或 `*斜体*`；光标离开后，页面又恢复平常的显示。

工具栏的命令和菜单相同。选中一个词并点击 **粗体**，或者使用键盘：

| 操作 | 快捷键 |
| --- | --- |
| 撤销 | ⌘Z |
| 查找 | ⌘F |
| 保存 | ⌘S |
| 新建笔记 | ⌘N |

在 Windows 和 Linux 上，用 Ctrl 代替 ⌘。

## 用 frontmatter 给笔记命名

顶部两条 `---` 之间的部分就是 **frontmatter**。其中的 `title` 是笔记的名字；即使正文没有
`# 一级标题`，它也充当最上层的标题。

```yaml
---
title: 一篇有名字的笔记
id: 20261017120000
keywords: 笔记, 示例
---
```

`id` 是笔记稳定的标识，wikilink 可以用它来链接。**设置 → 新建笔记** 决定每篇新笔记从什么
frontmatter 开始。

## 给页面搭结构

### 二级标题

#### 三级标题

段落之间用空行分开。在有助于阅读的地方使用 **粗体**、*斜体*、~~删除线~~ 和 `行内代码`。水平线
可以隔开想法：

---

项目符号列表、编号列表和任务列表都是普通 markdown：

- 一个项目
- 另一个项目
  - 嵌套的项目

1. 第一项
2. 第二项

- [ ] 尚未完成的任务
- [x] 已完成的任务

> 引用让一段话与正文保持距离。

表格用竖线书写：

| 功能 | 用法 |
| --- | --- |
| 粗体 | 选中文字并点击 **粗体** |
| 表格 | **插入 → 表格** |
| 代码 | 输入围栏代码块 |

## 代码、公式和注释

围栏代码块会原样保留代码：

```js
const answer = 42;
console.log(answer);
```

行内公式写在 `$E = mc^2$` 中。独立公式会占据自己的区块：

$$
\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}
$$

脚注是句子里的引用和正文下方的一条说明。[^1]

[^1]: 这是脚注的文字。编号由 Yi 处理。

## 链接笔记和图片

wikilink 按标题、文件名或 id 连接笔记，例如 `[[另一篇笔记]]`。输入 `[[` 时，Yi 会列出它找到的
笔记。普通网页链接写成 `[显示的文字](https://example.com)`。

图片是普通的 markdown 图片：`![说明](picture.png)`。相对路径先在笔记旁边查找，再到
**设置 → 通用** 指定的图片文件夹里查找。图片按钮可以从文件或剪贴板插入图片。

## 引用你读过的资料

引用使用 pandoc 语法：`[@smith2020]`。在 **设置 → 引用** 中选择参考文献文件和引用样式；Yi 会在
页面中显示格式化后的引用，并在导出时把引用的作品列在参考文献下。

## 查找与替换

**编辑 → 查找** 会在笔记中搜索；**编辑 → 替换** 会替换一处或全部匹配。搜索可以在显示的页面中
进行，也可以在代码块的源代码中进行。

## 导出笔记

**文件 → 导出** 提供 Word 文档、OpenDocument 文件、LaTeX、HTML、EPUB 电子书、PDF 和应用自己
处理的 markdown。卡片会写明要写出的文件和使用的转换设置。图片会被带入输出；当所选格式无法容纳
SVG 或 WebP 时，Yi 会把它们绘制成 PNG。

## 保存版本

**文件 → 保存一个版本** 会把笔记的当前状态保存在 git 仓库里。只有你主动要求时才会创建版本，
版本面板可以让你阅读旧副本并与当前文字比较。

## 让应用适合你

**设置** 可以更改语言、工作区、图片文件夹、引用、新笔记模板，以及未保存的文档是否在堆叠中打开。
更改设置时会立即保存。

应用会记住你打开过的文档和你在其中的位置。关闭窗口再打开，同一页会回来。

## 一篇可以试写的笔记

把下面这段复制到新笔记里，再改一改：

```markdown
---
title: 我的第一篇笔记
---

## 我在写什么

一个有**分量**的想法，一个[链接](https://example.com)，还有一条脚注。[^1]

一个公式：$a^2 + b^2 = c^2$。

[^1]: 线下的注释。
```

这就是一篇 Yi 笔记的全部形状：纯文本、一点 markdown，以及写作时容易阅读的页面。
