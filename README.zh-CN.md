# Yi

[English](README.md)

Yi 是一款本地优先的所见即所得 Markdown 编辑器，面向笔记、研究资料与长文写作。文件始终是普通
Markdown，同时内置链接、交叉引用、文献引用、数学公式与 Pandoc 模板导出。

## 适合谁

Yi 面向希望保留 Markdown 文件所有权，同时需要引用、交叉引用、数学公式和出版级导出的研究人员、
学者与长文写作者。

## 为什么选择 Yi

- 保留原生 Markdown 的所见即所得编辑
- 面向研究写作的文献引用、交叉引用、公式与定理块
- 可复用的 Word、LaTeX、EPUB、HTML 与 PDF 模板包
